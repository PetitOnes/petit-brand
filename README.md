# petit-brand

ぷち(PetitOnes)の見た目の正本: 名前の表記・色・書体・顔。中身は [brand.md](brand.md)、値は [tokens.css](tokens.css)、顔は `assets/`。
ページ: https://petitones.github.io/petit-brand/ (tokens の見本)

- 版は `VERSION`。main に入ると CI が同じ名前のタグ(`v1.0.0`)と Release を作る
- 直すときは PR で。画面側(TeamPuchi/petit-ui)の値と食い違わせない
- 運用の情報(誰が持ち主か、配信の手順、未公開の計画)はここに書かない(ちーむぷちの非公開リポにある)

ぷちは PetitOnes(ありさん)のプロジェクトです。
